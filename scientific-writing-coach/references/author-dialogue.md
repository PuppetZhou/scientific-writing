# 作者问答：先澄清论证

## 从稿件定位问题

不要先发一份泛化问卷。先读取稿件，尝试填出以下工作记录；只问空缺、矛盾或会改变结论的地方。

| 项目 | 需要明确的内容 |
|---|---|
| 研究问题 | 对什么对象、在什么条件下、回答什么未知？ |
| 核心主张 | 最希望读者记住哪一个答案？RP中是待检验目标。 |
| 决定性证据 | 哪组数据、比较或实验最直接支持它？ |
| 替代解释 | 相同现象还能由什么造成？已排除到什么程度？ |
| 创新位置 | 相比哪项已有工作，多回答了什么？ |
| 范围 | 哪些任务必须完成，哪些只是拓展或远景？ |

## 追问的写法

每个问题包含“稿件中的具体疑点＋需要作者做出的判断”。优先问会影响文章走向的问题，再问局部信息。

- **主张不明确：**“摘要同时强调准确率和机制解释。你已有哪一类直接证据？这会决定摘要结尾以性能贡献还是机制发现为主。”
- **比较不公平：**“模型A用了临床标签，B没有。你要比较实际预测能力，还是证明架构本身更好？后者需要控制训练信息。”
- **证据越界：**“这里写‘导致’，但当前给的是相关性。是否还有干预证据？如果没有，我会把因果表述改为关联。”
- **RP范围过大：**“三个目标中，哪一个是必须完成的交付？哪些可以在数据或时间不足时缩减？”
- **缺口不成立：**“你引用的方法已使用结构信息。新的问题是特征更细、训练目标不同，还是泛化表现尚不清楚？”

可给2–3个容易比较的选项，并允许自由回答。不要让作者在不理解差异时选择技术名称。

## 处理回答

收到答案后，简短复述它对文章的影响，例如：“因此主张保留在预测性能层面，分子机制改为拓展解释。”随后修改受影响的段落及依赖结论，不能只在原句后附加一句。

维护本轮会话的简短决定记录，不必每次创建额外文件。记录已确认的目标、证据、术语、范围和未决问题。后续问答围绕新缺口推进，避免重复询问。

## 何时等待、何时继续

- 缺失结果、效应方向、关键比较或作者核心立场：提问后暂停依赖这些信息的结论；继续做独立结构检查。
- 缺失非关键日期、格式或表述偏好：采用合理临时安排并说明，不阻断全部写作。
- 作者说“直接改”：不强制完成问答仪式；保留证据边界，必要处标出待补信息。
- 不要求作者确认每一句润色。提问是澄清研究，不是索取操作许可。
