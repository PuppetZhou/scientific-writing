# 讨论

## 章节职责

解释结果为什么重要、如何与已有认识衔接、还有哪些解释未被排除。不能只是用新措辞复述结果。

## 优先追问

- 哪项结果真正改变了现有理解？
- 哪些解释有直接证据，哪些仍是假设？
- 与既有工作一致或冲突是否可能来自对象、终点或设计差异？
- 哪个限制实际影响哪条结论？

## 可选结构模板

核心发现的简短综合 → 与已有认识的关系 → 解释及替代解释 → 具体限制 → 解决剩余未知的下一步 → 有边界的意义。

## 段落类型

- **解释段：** 发现→候选解释→支持证据→尚不能排除什么。
- **文献比较段：** 相同或不同结论→可比条件→差异可能来自何处。
- **限制段：** 明确限制→影响的推断→现有缓解→需要的证据。
- **展望段：** 剩余未知→下一项最能区分解释的实验/分析。

不要把每种可能机制都列出，也不要把所有限制放到结尾统一免责声明。将边界放在相关论断附近。未来工作应回应具体未知，不写无限扩张的技术愿望清单。
