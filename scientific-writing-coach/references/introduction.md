# 引言

## 章节职责

论证具体研究目标的合理性。让读者从已知问题走到尚未解决、又可回答的问题。

## 优先追问

- 大问题是什么，谁受它影响？
- 为什么聚焦这类对象或场景，而不是所有对象？
- 现有最接近的研究已经解决到哪一步？
- 哪个未知会改变我们的认识或实践？

## 可选段落模板

1. **定位段：** 领域中与本研究直接相关的需求及后果。
2. **收窄段：** 特定对象的困难，以及已有证据。
3. **缺口段：** 现有能力的具体边界，导出待回答问题。
4. **研究段：** 本文问题、总体路线和范围；按学科惯例决定是否简要预告发现。

段数可合并，不要求四段齐全。总漏斗是“重要问题→具体困难→已知/未知→当前问题与路线”。

## 逻辑陷阱

- 不能从“对象重要”直接跳到“我的方法必要”，中间需要具体困难。
- “没有人用模型X”通常只是方案缺位，不是科学缺口。
- 单个数据集的覆盖限制不能推出所有模型无效。
- 引言不提前展开全部实施细节，不重复摘要的完整清单。

英文转折应承接真实证据，例如“However, these evaluations do not establish whether [specific transfer/generalisation question].”先确认前文评价确实未覆盖该问题。
