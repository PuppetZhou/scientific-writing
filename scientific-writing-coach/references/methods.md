# 方法与研究设计

## 章节职责

解释设计怎样回答问题，使读者能判断比较是否公平、证据是否有效。已完成研究提供实际实施信息；研究计划区分既定原则与待选参数。

## 优先追问

- 每个目标由哪种比较或实验直接检验？
- 对照/基线是什么，哪些条件保持一致？
- 样本、标签、实验单位和排除标准如何定义？
- 模型选择与最终测试是否使用不同信息？
- 哪些细节已执行，哪些只是拟议选项？

## 方法段模板

本步骤要解决的未知 → 设计选择及理由 → 输入/操作 → 对照与输出 → 如何判断该步骤有用。

全文可按数据→设计→实施→评价安排；具体结构应服从研究过程。湿实验围绕对照、干预、测量与实验单位；计算研究围绕数据、学习目标、基线、隔离和泛化。

## 关键检查

- 区分训练集、开发验证集和最终测试集，特征选择及校准属于开发。
- 比较架构效果时控制可用信息；不同输入条件下的工具比较可以成立，但需说明它回答的是实际能力而非纯架构优劣。
- 每个新增模块都对应一个消融或可检验理由，避免候选技术清单。
- 已完成论文不能用“常规方法”替代关键可复现参数；RP不能补造未确定的样本量或预算。
- 评价指标与问题对应，区分统计显著、效应大小、区间估计和应用价值。
