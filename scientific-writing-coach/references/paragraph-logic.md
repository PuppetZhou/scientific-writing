# 段落逻辑

## 逆向提纲

为现有每段写一个功能标签，如“定义问题”“比较策略”“呈现关键结果”“排除替代解释”。再用一句话概括其主张。连续两段功能与主张相同，通常需要合并；一段有两个独立主张，通常需要拆分。

检查链条：问题是否导出目标，目标是否有对应方法，方法是否产生所需证据，证据是否支持结论。不能用过渡词掩盖缺少的推理步骤。

## 按段落职责选择结构

| 段落类型 | 可用结构 | 常见错误 |
|---|---|---|
| 背景定位 | 已知背景→具体困难→为什么影响本研究 | 泛泛介绍领域重要性 |
| 缺口论证 | 已做到的事→证据范围→尚未知的问题 | 把“没有用我的方法”当科学缺口 |
| 方法选择 | 要回答的问题→设计选择→决定性比较 | 罗列技术名称 |
| 结果呈现 | 结果要点→关键比较和数据→局部解释 | 先写操作流水账，最后才说发现 |
| 讨论解释 | 发现→可能解释→证据/替代解释→边界 | 换词重复结果 |
| 限制说明 | 具体限制→影响哪个主张→应对或下一步 | 泛泛说样本少、仍需更多研究 |

不要求每段都有转折或限制；只保留服务本段任务的动作。

## 连贯性检查

1. 只读首句，能否看见论文推进？
2. 后一句是否接住前一句提出的对象或问题？
3. “因此”“然而”对应的是因果、推论、反例，还是只是换话题？
4. 段末是否引出下一步，而非重复段首？
5. 删除本段后，读者是否少了接受主张所必需的信息？

新增内容触发删除检查：已有句子承担同一功能时优先替换、合并。核心主张可在引言介绍、结果支撑、讨论解释，但三处必须承担不同职责。
