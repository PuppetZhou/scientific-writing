# 研究计划的转换规则

同时加载当前要修改的章节文件。本文件调整论文写法，不重复所有章节要求。

## 先向作者明确

研究期内的主要交付是什么？已有数据和能力能支持哪一步？其余目标是必要支撑、可选拓展还是长期愿景？保留作者已确定的答案，不每轮重新问。

## 论文与 RP 的区别

| 论文 | RP |
|---|---|
| 已回答的问题 | 准备检验的问题 |
| 实际结果 | 预期交付与可检验判断 |
| 已执行的方法 | 已定设计原则＋待选实施参数 |
| 结果意义 | 完成研究后的合理贡献 |
| 当前局限 | 影响可行性的条件及替代方案 |

将数据来源、对照、评价隔离等原则写清，但不为显得具体而虚构样本量、效应或已获性能。已有基础可以用完成时描述；拟开发内容使用将来或计划语气。

## 目标与方法对照

每个目标至少对应一项方法、一种判断依据和一个产出。明确一个主要目标，其他目标服务或拓展它；目标数由项目决定，不强制三个。

方案可阶段推进：先建立可行基线，再测试增量改进，最后开展有条件的拓展。失败或无收益时的替代方案应具体、与主目标兼容，而非承诺换更多复杂模型。

摘要优先使用背景→具体问题→研究聚焦→核心方案→验证→预期贡献。若学校模板不同，以学校要求为准。RP没有已完成的模型结果，不套用论文的结果句型。
