# 文献综述与相关工作

## 章节职责

组织比较，界定研究位置。以问题、证据来源或策略分组，避免按作者逐篇排列。

## 优先追问

- 最接近的工作是谁，其证据支持到什么程度？
- 比较的是同一对象、任务、终点和数据条件吗？
- 所谓缺陷是原文承认、你有证据指出，还是尚待测试？

## 一组文献的模板

共同问题 → 已有策略及有效之处 → 方法间的关键差别 → 证据范围/不一致 → 本研究拟补充的问题。

可采用情境—冲突—问题—解法，但不人为制造冲突，也不把文献否定一遍来衬托自己。

## 实用比较维度

根据任务选取少量关键维度：输入信息、监督来源、预测终点、对象覆盖、评价隔离、计算成本。不要把所有维度都塞进正文；必要时用表格帮助比较。

每条引用应支持所在句子的具体判断。读到综述的解释就归因综述，涉及原研究结果则优先核对原文。不因用户给出引用数量目标而添加无关研究。

缺少文献支持时，指出待验证的陈述，必要时开展用户授权范围内的检索，不编造题录或结论。
